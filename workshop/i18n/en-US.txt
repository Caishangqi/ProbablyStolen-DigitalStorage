[h1]Digital Storage[/h1]

Connect your inventory to a searchable digital storage network. Craft storage cells, place them in drives, then use a controller and terminal to manage items across the network.

[b]Inspired by[/b]

The digital storage and network terminal design in this mod is inspired by [url=https://github.com/AppliedEnergistics/Applied-Energistics-2]Applied Energistics 2[/url], adapted to Probably Stolen's item, machine, and inventory rules.

[h2]Machines[/h2]

[b]Controller[/b]
Manages power for the connected network. Put a battery in the controller's power slot. Each network can have only one controller.

[b]Drive[/b]
A connected drive holds 14 individual storage cells. Drives can connect to other drives, terminals, and controllers as part of the same network.

[b]Terminal[/b]
The player's access point to the digital inventory. The terminal lets you search, sort, store, and take items from the network, as well as configure storage cell partitions.

[h2]Storage cells[/h2]

Assemble a storage cell by inserting a component into an Item Cell Housing. Components and cells come in five tiers: 1k, 4k, 16k, 64k, and 256k. Place an assembled cell in a drive to access its contents through the terminal.

Cell capacity is measured in bytes:

[list]
[*]1k: 1,024 bytes
[*]4k: 4,096 bytes
[*]16k: 16,384 bytes
[*]64k: 65,536 bytes
[*]256k: 262,144 bytes
[/list]

Each new item type first costs a fixed type overhead (4 bytes on a 1k cell, multiplied by 4 for each higher tier). Items then cost their count times their footprint, at 8 grid cells per byte. For example, on a 1k cell ten 2x2 items take 40 cells, or 5 bytes. Every tier holds up to 128 different item types; at 128 types the type overhead uses exactly half of the capacity.

Items are sorted by size onto the cell's internal storage pages automatically, so there is nothing to arrange. A single item wider or taller than 12 cells does not fit. Storage pages are locked, so items move in and out through a terminal. Emptied pages are removed automatically.

Hover over a cell to see its bytes used, item types, partition, and storage format version. Empty a cell before removing its component; disassembly returns the housing to a single empty page.

Storage components and assembled cells can appear in merchant stock. Larger tiers are rarer.

[h2]Basic setup[/h2]

[list]
[*]Get an Item Cell Housing and a storage component.
[*]Insert the component into the housing to assemble a storage cell of the same tier.
[*]Place the storage cell in one of the drive's 14 slots.
[*]Place the controller, drive, and terminal in the same network, then power the controller.
[*]Open the terminal to search, store, or take items.
[/list]

[h2]How the network works[/h2]

A network is made from machines that are physically connected. Machines connect when their occupied edges touch. Corner contact does not connect them. Machines can form a chain or branch from an existing connection. Machines in different native inventory grids cannot connect to each other.

[b]Network status[/b]

[list]
[*][b]Online[/b]: The network has one controller and enough power to cover its current usage.
[*][b]Offline (unpowered)[/b]: The machines are still connected, but the controller does not have enough power. Restore the power source to bring the network back online.
[*][b]No controller[/b]: The current connected group does not contain a controller.
[*][b]Controller conflict[/b]: Multiple controllers are in the same network. Separate them into different networks.
[/list]

The controller, each drive, and each terminal consume network power during the game's nightly cycle. Their default usage is 3, 2, and 1 respectively. These values can be changed in the mod settings.

[b]Partitions[/b]

A partition is a list of items that a storage cell is allowed to accept. Once configured, a cell only accepts items on its list. Partitions help keep different items in separate cells and let you control which cells are preferred when storing items.

[b]Drive priority[/b]

Drives can have a priority value. When storing items, the system uses higher-priority drives first. When taking items, it uses lower-priority drives first.

[h2]Finding items[/h2]

Search item names and descriptions directly, or narrow the search with a prefix:

[list]
[*][b]#[/b] searches enabled tags, including translated type names when the matching tag is present.
[*][b]@[/b] searches item types and their translated names.
[*][b]$[/b] searches item descriptions and lore.
[*][b]&[/b] searches item IDs. Enable identifier search in the mod settings first.
[/list]

Separate terms with spaces to require all of them, use [b]|[/b] to match either group, and put [b]-[/b] before a term to exclude it. Double quotes keep a phrase together. Search colors distinguish prefixes and operators; a query with no matches turns red. Field search modes and syntax colors can be changed in the mod settings.

Pinyin search supports full spelling, initials, and mixed Chinese and pinyin input. For example, [b]cailiao[/b], [b]cl[/b], and [b]cai料[/b] can find text containing "材料". Choose from nine keyboard layouts, including Quanpin, Daqian, Xiaohe, and Ziranma, with optional fuzzy spelling rules. Pinyin also works within prefix searches when the selected field contains Chinese text.

Pinyin defaults to [b]Auto[/b]: it is enabled when the game uses Chinese and disabled for other languages. Choose [b]On[/b] or [b]Off[/b] to keep your preference regardless of the game language.

[h2]Terminal controls[/h2]

[list]
[*]Use the toolbar to change sorting and window size, or scroll through the results.
[*]Hover over a result to read its tooltip while keeping the search box focused.
[*]Left-click to take one stack. Non-stackable items are taken one at a time.
[*]Right-click to take half a stack. Stored stacks are not split.
[*]Shift + left-click to take the entire available amount of that item.
[*]Drag a whole stack onto the terminal grid or an item already shown in the terminal to try to store it.
[*]Rejected items stay where they were. Common reasons include not enough free bytes, the item type limit being reached, an item being too large, a partition mismatch, or an offline network.
[/list]

The terminal and drive can open the game's native module panel. In the current version, native module properties do not change Digital Storage capacity, throughput, or power consumption.

[h2]Upgrading from an older version[/h2]

Version 0.4.0 updates the component storage format (v1 to v2). Please back up your save file before upgrading.

[list]
[*]When you load a save, existing cells are reorganized automatically without losing items. Afterwards the cell tooltip shows "Storage format v2".
[*]If a cell cannot fit its items after reorganizing, it stays as it is and only lets you take items out; its tooltip shows "Pending migration". Take some items out, save, and load again to finish.
[*]Future versions that change the storage format only convert the previous format. If you skipped a version, upgrade in order: install the skipped version, load and save, check that no cell shows "Pending migration", then install the newer version. Cells in a format that is too old are locked; their items are kept, and the tooltip names the version to install first.
[*]Downgrading is not supported. Older versions of the mod show upgraded cells as unavailable; do not save in that case.
[*]If a "Do not save" warning appears, quit the game. Your last save is still intact.
[/list]

[h2]Compatibility and notes[/h2]

The current version targets Probably Stolen 0.46D (Steam build 26525552). Compatibility with other game versions is not guaranteed.

Before disabling or uninstalling the mod, take all items out of every storage cell through a terminal. Treat a storage cell with contents, or a drive with storage cells, as a container holding a complete inventory.
