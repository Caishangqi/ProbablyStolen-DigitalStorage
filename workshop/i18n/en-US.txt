[h1]Digital Storage[/h1]

Put storage cells in drives and use a terminal to find, store, and retrieve items across the network.

The storage network takes inspiration from [url=https://github.com/AppliedEnergistics/Applied-Energistics-2]Applied Energistics 2[/url] and uses Probably Stolen's item, machine, and inventory rules.

[h2]Getting started with Wild[/h2]
Unlock Digital Storage Basics in Wild's Digital Storage tab to get a controller with a battery, a drive, a terminal, and an empty 1k storage cell. The Data Scientist visits on the same day as the retired farmer and sells storage equipment without buying it back.

Advanced Data Management gives you a Cell Workbench, an Equal Distribution Module, a Stack Display Module, and a Type Limit Module. The Data Scientist then rotates advanced stock weekly, while Dr. Jackson always brings storage modules and high-capacity components.

[h2]Machines and setup[/h2]
[list]
[*]Controller: put a battery in its power slot to power connected machines. Each network needs exactly one controller.
[*]Drive: holds 14 individual storage cells and connects to other drives, terminals, and controllers.
[*]Terminal: searches, sorts, stores, and takes items from the network.
[*]Cell Workbench: a 3x3 machine for partitions and cell modules. It needs no network connection or power.
[/list]

Put a storage component in an Item Cell Housing to assemble a cell of the same tier. Load it into a drive and connect the drive and terminal to a powered controller.

To configure a cell, move it from the drive to the workbench, where its contents are out of the network. The workbench accepts usable, assembled cells you own in a valid storage format.

[h2]Capacity and storage cells[/h2]
Components and cells come in five tiers:
[list]
[*]1k: 1,024 bytes
[*]4k: 4,096 bytes
[*]16k: 16,384 bytes
[*]64k: 65,536 bytes
[*]256k: 262,144 bytes
[/list]
Each tier starts with a 128-type limit. Type overhead takes half the capacity at the effective type limit. Type Limit Modules spread that overhead across more types without adding bytes.

Items use one byte per eight grid squares of combined bounding area, rounded up. Ten identical 2x2 items in an unmodified 1k cell use 9 bytes (5 for the items and 4 for their type).

Items are grouped by size on locked pages that disappear when empty. The terminal handles all transfers. Items wider or taller than 12 squares do not fit.

Hover over a cell to see its capacity, partition, and modules. Before removing the component, empty the cell and remove all modules and rules. The housing returns to one empty page, keeping its partition mode and expansion level.

[h2]Cell modules[/h2]
Cell modules take up 2x2 squares and fit only in cells. Use the workbench's Modules panel to install or remove them.
[list]
[*]Type Limit Modules come in Common, Rare, and Epic qualities with random +N and +P% bonuses. The limit is (128 + total flat bonus) x (1 + total percentage), rounded down. Install as many as the bay can hold.
[*]One Equal Distribution Module per cell caps each type's usage at the usable item space divided by the effective type limit. The cap does not depend on rule count.
[/list]
Take items out first if removing a Type Limit Module would put the cell over its type or byte limit.

Native Module Bay Expansion Kits work only on 16k and 64k cells (one level each) and 256k cells (up to two). Each level adds 100 to item value. Expanded housings require a component that supports their expansion level.

[h2]Partition rules[/h2]
At the workbench, select Configure Partition and drag an inventory item onto the grid to make a sample rule. The item stays in your inventory.

New cells start in Whitelist mode. Use the mode button to switch to Blacklist. The whitelist admits matches and the blacklist blocks them. An empty list accepts everything in either mode.

Double-click a rule to edit its item, type, legality, stolen status, heat, or visible feature conditions. An item matches a rule only if it meets all its conditions. One matching rule is enough. Changes only affect new deposits.
[list]
[*]Drag rules to move or swap them. Position does not affect matching or storage priority.
[*]Copy, rename, or delete rules, and undo deletion or clearing.
[*]The rule limit follows the effective type limit. Lowering it keeps existing rules but prevents additions while over the limit.
[*]Overview edits and valid detail edits save automatically. Invalid input shows Not saved.
[*]Press Back to close the attribute menu, return to the overview, or close the editor. Picking up the cell or closing the workbench also closes it.
[/list]
[h2]Networks and priority[/h2]
Machines connect along shared edges in the same inventory grid, forming chains or branches.

Status shows Online, Offline (unpowered), No controller, or Controller conflict. An offline network stays connected. Restore power or move extra controllers to separate networks as needed.

Nightly power usage defaults to 3 for a controller, 2 per drive, and 1 per terminal. Change these values in the mod settings.

Storage tries higher-priority drives first; extraction starts with lower-priority drives. Within a priority group, cells with a matching whitelist rule are preferred. Blacklist admission adds no preference.

[h2]Finding items[/h2]
Search part of a name or description, or use a prefix:
[list]
[*][b]#[/b] enabled tags. If a tag shares its name with an item type, the search also includes that type's translated name.
[*][b]@[/b] item types and their translations.
[*][b]$[/b] descriptions and lore.
[*][b]&[/b] item IDs; enable identifier search in settings first.
[/list]
Spaces require all terms, [b]|[/b] matches either group, and [b]-[/b] excludes a term. Double quotes keep phrases together. The search box turns red when nothing matches. Search scope and colors can be adjusted in settings.

Pinyin supports full spelling, initials, mixed Chinese and English input, and prefix searches. [b]cailiao[/b], [b]cl[/b], and [b]cai料[/b] all find 材料. Settings offer nine keyboard layouts and fuzzy pinyin.

Auto enables pinyin only in Chinese. Choose On or Off to override it.

[h2]Terminal controls[/h2]
[list]
[*]Use the toolbar for sorting and window size; scroll to browse. Tooltips work while the search box has focus.
[*]Left-click takes one stack, or one non-stackable item. Right-click takes half a stack; stored stacks are not split. Shift + left-click takes the full available amount.
[*]Drag a whole stack onto the terminal grid or a displayed item to store it. Items that do not transfer stay in place.
[*]Insertion may be refused for insufficient bytes, type limits, oversized items, partition mismatch, or an offline network.
[/list]
Terminals and drives can open the native module panel. Native module properties currently do not change digital storage capacity, throughput, or network power usage.
