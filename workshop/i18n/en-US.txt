[h1]Digital Storage[/h1]

Put storage cells in drives and use a terminal to find, store, and retrieve items across the network.

The storage network takes inspiration from [url=https://github.com/AppliedEnergistics/Applied-Energistics-2]Applied Energistics 2[/url] and uses Probably Stolen's item, machine, and inventory rules.

[h2]Getting started with Wild[/h2]
In Wild's Digital Storage tab, unlock Digital Storage Basics for a controller with a battery, a drive, a terminal, and an empty 1k cell. The Data Scientist visits on the retired farmer's day, sells storage gear, and buys standalone components at a discount (up to 800 per visit).

Advanced Data Management gives you a Cell Workbench and one each of the Equal Distribution, Stack Display, and Type Limit Modules. The Data Scientist rotates advanced stock weekly, and Dr. Jackson stocks modules and components. Merchants stock components up to 4k at first, up to 64k after Advanced, and up to 256k after Expert.

Expert Data Management gives you an IO Port. Dr. Jackson and the Data Scientist then each try to stock a 256k component and an IO Port on each visit.

[h2]Machines and setup[/h2]
[list]
[*]Controller: one per network. Put a battery in its power slot.
[*]Drive: holds 14 storage cells.
[*]Terminal: searches, sorts, stores, and retrieves network items.
[*]Cell Workbench: a standalone, unpowered 3x3 machine for configuring partitions and cell modules.
[/list]

Put a storage component in an Item Cell Housing to build a cell of the same tier. Load it into a drive and connect the drive and terminal to a powered controller. The workbench accepts usable, assembled cells you own in a valid format. A cell in the workbench is out of the network.

[h2]IO Port[/h2]
Connect the 3x3 IO Port to a powered network. Load up to six storage cells on the left and choose Cell to network or Network to cell. Set the port to eject cells when they're empty, full, or done transferring, then press Start. Take processed cells from the right. Transfers use network power and respect the destination cell's partition and capacity. Remove all cells and modules before destroying the port.

[h2]Capacity and storage cells[/h2]
Components and cells come in five tiers:
[list]
[*]1k: 1,024 bytes, 256 types
[*]4k: 4,096 bytes, 1,024 types
[*]16k: 16,384 bytes, 4,096 types
[*]64k: 65,536 bytes, 16,384 types
[*]256k: 262,144 bytes, 65,536 types
[/list]
Type overhead takes half the capacity at the type limit. Type Limit Modules spread this overhead across more types. Existing cells use the new limits without a save migration.

Items use one byte per eight squares of combined bounding area, rounded up. Ten identical 2x2 items in an unmodified 1k cell use 7 bytes (5 for the items and 2 for their type).

Cells group items by size on locked pages and remove empty pages. Items over 12 squares in either dimension do not fit.

Hover over a cell to see capacity, partition, and modules. Before removing its component, empty the cell and remove its modules and rules. The housing returns to one empty page and keeps its partition mode and expansion level.

[h2]Cell modules[/h2]
Install or remove 2x2 cell modules in the workbench's Modules panel. They fit only in cells.
[list]
[*]Type Limit Module rolls: Common +80 to 160 types and +5 to 10%; Rare +160 to 320 and +10 to 20%; Epic +320 to 640 and +20 to 30%. Add flat bonuses to the tier's base limit, apply the sum of the percentages, and round down. Install as many as the bay fits. Existing modules keep their rolls and get the higher flat bonus.
[*]One Equal Distribution Module per cell caps each type's area at half the cell's byte capacity converted to grid squares, divided by the partition rule limit and rounded up.
[/list]
Take items out first if removing a Type Limit Module would put the cell over its type or byte limit.

Native Module Bay Expansion Kits work on 16k and 64k cells (one level) and 256k cells (up to two). Each level adds 100 to item value. A component must support its housing's expansion level.

[h2]Partition rules[/h2]
At the workbench, open Configure Partition and drag an inventory item onto the grid to create a rule. The sample stays in your inventory.

New cells start with a whitelist that admits matches. Switch to a blacklist to reject matches. An empty list accepts everything in either mode.

Double-click a rule to edit item, type, legality, stolen status, heat, or visible features. A match must satisfy every condition in any one rule. Edits affect future deposits only.
[list]
[*]Move or swap rules by dragging. Order does not affect matching or priority.
[*]Copy, rename, or delete rules. You can undo deletion or clearing.
[*]All tiers start with 128 rule slots. Use the type limit formula with one tenth of each listed flat bonus and the same percentage bonuses. Lowering the limit keeps existing rules but blocks additions until there is room.
[*]Valid edits save automatically. Invalid input shows Not saved.
[*]Back closes the attribute menu, returns to the overview, or closes the editor. Removing the cell or closing the workbench also closes it.
[/list]

[h2]Networks and priority[/h2]
Machines connect along shared edges in the same inventory grid. If the network is offline, restore power. If controllers conflict, split them into separate networks.

Nightly power defaults to 3 for a controller, 2 per drive, 1 per terminal, and 0 per IO Port before transfer fees. Change these in mod settings.

Deposits start with higher-priority drives and withdrawals with lower-priority ones. At equal priority, matching whitelist rules give cells first chance at deposits.

[h2]Finding items[/h2]
Search part of a name or description, or use a prefix:
[list]
[*][b]#[/b] enabled tags. If a tag shares its name with an item type, the search also includes that type's translated name.
[*][b]@[/b] item types and their translations.
[*][b]$[/b] descriptions and lore.
[*][b]&[/b] item IDs; enable identifier search in settings first.
[/list]
Spaces require all terms, [b]|[/b] matches either group, and [b]-[/b] excludes a term. Double quotes keep phrases together. No matches turn the search box red. Change search scope and colors in settings.

Pinyin works with prefixes, full spelling, initials, or mixed Chinese and English input: [b]cailiao[/b], [b]cl[/b], and [b]cai料[/b] find 材料. Settings include nine layouts and fuzzy pinyin. Auto enables it only in Chinese; use On or Off to override.

[h2]Terminal controls[/h2]
[list]
[*]Use the toolbar to sort or resize the window. Scroll to browse. Tooltips work while searching.
[*]Left-click takes one item. Right-click takes half the slot's items, rounded up. Shift-click takes all. A stored stack counts as one item.
[*]Drag from a single slot to place one item, or hold Shift as you start to drag all. Release Shift once dragging. Scroll to add or remove one per notch, or right-click to halve the amount, rounded up.
[*]Drag items onto the terminal grid or a displayed item to store them. Unstored items stay in place.
[*]Capacity, type limits, size, partitions or an offline network can prevent insertion.
[/list]
Terminals and drives can open the native module panel. Native module properties currently do not change digital storage capacity, throughput, or network power usage.
