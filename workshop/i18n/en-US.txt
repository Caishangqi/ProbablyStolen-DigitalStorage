[h1]Digital Storage[/h1]

Put storage cells in drives and use a terminal to find, store, and retrieve items across the network.

The network draws on [url=https://github.com/AppliedEnergistics/Applied-Energistics-2]Applied Energistics 2[/url] and follows Probably Stolen's item, machine, and inventory rules.

[h2]Getting started with Wild[/h2]
In Wild's Digital Storage tab, unlock Digital Storage Basics for a controller with a battery, a drive, a terminal, and an empty 1k cell. The Data Scientist visits on the retired farmer's day to sell gear and buy standalone components at a discount (up to 800 per visit).

Advanced Data Management grants a Cell Workbench, an Equal Distribution Module, a Stack Display Module, and a Type Limit Module. The Data Scientist rotates advanced stock weekly. Dr. Jackson stocks modules and components. The component cap rises from 4k to 64k with Advanced and to 256k with Expert.

Expert Data Management grants an IO Port. Dr. Jackson and the Data Scientist then try to stock one IO Port and one 256k component each per visit.

[h2]Machines and setup[/h2]
[list]
[*]Controller: one per network. Put a battery in its power slot.
[*]Drive: holds 14 storage cells.
[*]Terminal: searches, sorts, stores, and retrieves network items.
[*]Cell Workbench: a standalone, unpowered 3x3 machine for configuring partitions and cell modules.
[/list]

Put a component in an Item Cell Housing to assemble a cell of the same tier. Load it into a drive and connect the drive and terminal to a powered controller. The workbench takes usable, assembled cells you own in a valid format. These cells stay outside the network.

[h2]IO Port[/h2]
Connect the 3x3 IO Port to a powered network. Load up to six cells on the left, choose a transfer direction, and pick when to eject (empty, full, or work complete). Press Start and collect processed cells on the right. Transfers use network power and follow the destination's partition and capacity limits. Remove cells and modules before destroying the port.

[h2]Capacity and storage cells[/h2]
Components and cells come in five tiers:
[list]
[*]1k: 1,024 bytes, 256 types
[*]4k: 4,096 bytes, 1,024 types
[*]16k: 16,384 bytes, 4,096 types
[*]64k: 65,536 bytes, 16,384 types
[*]256k: 262,144 bytes, 65,536 types
[/list]
Type overhead uses half the capacity at the type limit. Type Limit Modules spread it across more types. Existing cells need no save migration.

Items use one byte per eight squares of combined bounding area, rounded up. Ten identical 2x2 items in an unmodified 1k cell use 7 bytes (5 for items and 2 for type overhead).

Cells group items by size on locked pages and remove empty pages. Items over 12 squares in either dimension do not fit.

Hover over a cell to see capacity, partition, and modules. Before removing its component, empty the cell and remove its modules and rules. The housing returns to one empty page and keeps its partition mode and expansion level.

[h2]Cell modules[/h2]
Install or remove 2x2 cell modules in the workbench's Modules panel. They fit only in cells.
[list]
[*]Type Limit Module rolls: Common +80 to 160 types and +5 to 10%; Rare +160 to 320 and +10 to 20%; Epic +320 to 640 and +20 to 30%. Add flat bonuses to the tier's base limit, apply the sum of the percentages, and round down. Install as many as the bay fits. Existing modules keep their rolls and get the higher flat bonus.
[*]One Equal Distribution Module per cell caps each type's area at half the cell's byte capacity converted to grid squares, divided by the partition rule limit and rounded up.
[/list]
Take items out first if removing a Type Limit Module would put the cell over its type or byte limit.

Native Module Bay Expansion Kits work on 16k and 64k cells (one level) and 256k cells (up to two). Each level adds 100 to item value. A component must support its housing's expansion level.

[h2]Partition rules[/h2]
At the workbench, open Configure Partition and drag an item onto the grid to make a rule. You keep the item.

New cells use a whitelist to accept matches. Switch to a blacklist to reject matches. An empty list accepts everything in either mode.

Double-click a rule to edit item, type, legality, stolen status, heat, or visible features. An item matches if it meets all conditions in any one rule. Edits affect future deposits only.
[list]
[*]Move or swap rules by dragging. Order does not affect matching or priority.
[*]Copy, rename, or delete rules. You can undo deletion or clearing.
[*]All tiers start with 128 rule slots. Reuse the type limit formula with one tenth of each flat bonus and the same percentages. Lower limits keep existing rules but block new ones until there's room.
[*]Valid edits save automatically. Invalid input shows Not saved.
[*]Back closes the menu, returns to the overview, or closes the editor. Removing the cell or closing the workbench also closes the editor.
[/list]

[h2]Networks and priority[/h2]
Machines connect along shared edges in the same inventory grid. If the network is offline, restore power. If controllers conflict, split them into separate networks.

Nightly power defaults to 3 for a controller, 2 per drive, 1 per terminal, and 0 per IO Port before transfer fees. Change these in mod settings.

Deposits start with higher-priority drives and withdrawals with lower-priority ones. At equal priority, matching whitelist rules give cells first chance at deposits.

[h2]Finding items[/h2]
Search part of a name or description, or use a prefix:
[list]
[*][b]#[/b] enabled tags. If a tag shares its name with an item type, the search also includes that type's translated name.
[*][b]@[/b] item types and their translations.
[*][b]$[/b] descriptions and lore.
[*][b]&[/b] item IDs; enable identifier search in settings first.
[/list]
Spaces require all terms, [b]|[/b] matches either group, and [b]-[/b] excludes a term. Double quotes keep phrases together. No matches turn the search box red. Change search scope and colors in settings.

Pinyin works with prefixes, full spelling, initials, or mixed Chinese and English input: [b]cailiao[/b], [b]cl[/b], and [b]cai料[/b] find 材料. Settings include nine layouts and fuzzy pinyin. Auto enables it only in Chinese; use On or Off to override.

[h2]Terminal controls[/h2]
[list]
[*]Sort or resize with the toolbar. Scroll to browse. Tooltips work while searching.
[*]Left-click takes one item, right-click takes half the slot (rounded up), and Shift-click takes all. A stack counts as one item.
[*]Dragging one slot starts with one item. Hold Shift at the start to take all. During the drag, scroll to adjust by one or right-click to halve the amount (rounded up).
[*]Drop items onto the grid or a displayed item to store them. Unstored items stay in place.
[*]Capacity, type limits, size, partitions, or an offline network can prevent insertion.
[/list]
Terminals and drives have native module panels. Native module properties leave storage capacity, transfer rate, and power usage unchanged.

[h2]Stack Display Module[/h2]
Install it in the terminal's module bay. Box-select two or more slots with the same item ID and use Actions on the right to add their configurable differences as Ignore entries. Hover over a selected slot to see what keeps the groups apart.

Open Stack display rules on the left to search and toggle rules by item. Choose Match or Ignore for each attribute and click Apply. Each terminal has its own rules for grouping items on screen.
