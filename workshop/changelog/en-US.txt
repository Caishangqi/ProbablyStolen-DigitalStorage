0.7.1

The Stack Display Module now uses separate rules for each item ID. This update removes the old terminal-wide rules.

- Box-select two or more slots with the same item ID. Use Actions on the right to add their configurable differences as Ignore entries in a new or existing rule. Box-select a single merged slot to edit its rule or remove the entries that merged it.
- Open Stack display rules to search by item name, ID, or tag key. Rules can be turned on or off individually or in bulk. In the item editor, choose Match or Ignore for each attribute and click Apply to save.
- The drive's sidebar now opens dedicated priority and module pages. The priority page has a number field and step buttons.
- Drop several storage cells onto an empty slot in a drive or IO Port to fill the next available slots in the same grid. Dropping cells onto the machine icon fills compatible slots from the first row onward.
