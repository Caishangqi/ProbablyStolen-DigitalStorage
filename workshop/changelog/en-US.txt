0.5.9

Updated item tooltips and added more detail to storage error logs.

- Controller tooltips now show the total power demand of the connected network in the game's own power display.
- Storage cell, module and network device tooltips are handled separately. If one section fails, the remaining sections can still appear.
- Errors such as an unavailable storage cell, a failed module display update or a module bay restore failure now include the exception message, stack trace and relevant item or page details in Player.log.
- Added Storage diagnostics under Debug in the mod settings. It is off by default and records extra storage page and module bay structure details when enabled. Errors are still logged when it is off.
- Repeated storage errors are deduplicated and diagnostic output is limited. A logging failure will not interrupt item transfers.
- The reported issue where an existing storage cell becomes unavailable is still under investigation.
