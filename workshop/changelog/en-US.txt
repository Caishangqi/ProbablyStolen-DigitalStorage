0.7.2

The Stack Display Module now supports global rules for all items in a terminal, plus rules for individual items.

- An item rule takes precedence over the global rule for the same attribute. Use the terminal's Actions bar to add or remove global rules from a selection.
- Hover over a search box to see how to use it. The terminal explains active prefixes and operators, plus pinyin when it's on. The stacking rule editor shows what you can search for.
- Control tooltips can now widen to fit their text.
- Saved stack display settings from earlier versions are no longer read. Set up your stacking rules again after updating.
