0.5.5
重构了终端和分区面板，规格化模块拓展相关内容，为下个版本的终端模块拓展做准备
- 终端模块仓可使用原版模块仓扩容套件升级 10 次，最终开放 255 格。原版机器仍可升级 2 次，存储元件各档的扩容上限不变。
- 模块页面根据模块仓大小调整窗口，显示当前等级、升级上限和可用格数。返回终端时恢复原来的窗口尺寸和位置。
- 新增 content.v1 扩展接口。其他模组可通过 C# 注册或 JSON 资源定义模块仓及物品绑定，并向共享注册表添加内容。
- 修复方法重载导致模组启动失败的问题。
- 修正窗口拖拽组件和分区控件的重复创建、注册，解决 CanvasGroup 重复添加和控件 ID 重名的日志警告。
- 终端和分区按钮不再进入键盘焦点，避免干扰游戏原生导航。
- 补充独立 API 测试和注册流程的回归测试，覆盖 JSON 加载、跨模组注册和失败隔离。
- 模块仓扩容只接管本模组物品和其他模组明确注册的物品，原版机器和其他模组的机器保持原版行为。
- 模块仓恢复失败时写入日志，能取得模块仓时将其锁定，不再弹出提示窗口。
